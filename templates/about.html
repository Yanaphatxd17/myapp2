Welcome to SB Admin 2 powered by Django!

This application demonstrates layout template inheritance using Django's template system. By structuring files into a reusable base.html template, all pages (Dashboard, About Us, and Contact Us) share the same sidebar navigation, header, and footer structure dynamically.

Key Technologies Used:
  • Django Web Framework
  • Python Database API & Models (dynamic student directory table)
  • Bootstrap 4 (SB Admin 2 Theme)
  • Google Fonts & FontAwesome Icons
